# 四季轮转

依据三张视频截图重建的实时 3D 动画，包含悬浮唱片式草地、四季扇区过渡、金色狗尾巴草、黑白双猫，以及花瓣、草籽和雪花。两只猫各自轮换四套动作组合，包含探头再跳、走走闻闻、伏低短扑、扑后停一拍再走。起跳和落地时，猫的身形随高草时隐时现。爪边的草压弯后会回弹，冬季落爪会留下逐渐淡去的雪印。

在当前项目目录运行以下命令，并打开 <http://127.0.0.1:5173/>。

```bash
python3 -m http.server 5173 --bind 127.0.0.1
```

如果服务已在上一级 P5 目录启动，可直接访问 <http://127.0.0.1:5173/seasons/>。页面使用本地 Three.js 0.180.0 和 ES modules，通过 HTTP 服务打开即可运行。

- 暂停／继续：播放按钮，或画面获得焦点后按空格。
- 季节：点击春、夏、秋、冬，或拖动时间轴。112 秒完成完整四季循环。
- 播放速度：0.5×、1×、2×。
- 保存此刻：导出当前画面 PNG。
- 全屏：右上角按钮；不支持时会给出提示。
- 系统开启“减少动态效果”时，默认暂停；仍可拖动时间轴。

`scene.js` 中的 `SETTINGS` 控制草高、踩踏和雪印的消退速度、粒子数量及季节循环。`makeGrass` 把短绒与细弯的长叶交错种成小簇，草叶边缘采用多重采样覆盖柔化。`seasonGLSL` 控制季节的角度分布和两侧的渐变带，过渡中的草叶会错开变色。`makeWindMap` 生成风向和强度贴图，`windGLSL` 叠加两种尺度的游移阵风，草叶和花点采样同一个风场。猫爪的接触位置写入 256×256 贴图，草地通道控制草叶和花点的变形，积雪通道控制雪印的凹陷与明暗。`catRoutines` 编排每套动作的顺序、时长和途中停点。同一页面内可以按时间复现动作，刷新会重新打乱组合顺序。跳跃使用三次插值，行走根据爪子目标位置计算关节角，尾巴用四段骨骼驱动连续网格。
